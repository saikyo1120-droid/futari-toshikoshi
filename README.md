# ふたりの年越しぐらし

さいけうとゆいちゃんの年末年始（2026/12/30〜2027/1/4、天王寺の宿「レイラ」と京都の初詣・初日の出）のための、ふたり専用サイト。沖縄版「おめで島ぐらし」と同じ仕組みで、見た目を和モダンに作り替えたもの。

- 公開: GitHub Pages（`.github/workflows/pages.yml`）。`index.html` が唯一のソース。
- 保存先: Supabase（沖縄版と同じプロジェクト・同じ2アカウント）。データは `docs` テーブルの `ny_` で始まる collection、写真は `photos` バケットの `ny/` 以下に分けて保存するので、沖縄版のデータとは混ざりません。追加のSQLは不要（未設定なら `supabase_setup.sql` を実行）。
- 機能: しおり（古地図風の地図・当日モード・天気）、御朱印帳（スタンプ）、おみくじ（ミッション）、交換日記・手紙、アルバム（今日の一枚・軌跡マップ）、年越しグルメ帖、リザルト・思い出ムービー、年越しカウントダウン（12/31 23:50〜）。
- 天気: Open-Meteo（best_match / JMA・ECMWF・GFS・ICON）、気象庁（大阪府・京都府南部の予報・週間信頼度・警報・概況）、雨雲（気象庁ナウキャスト→RainViewer）。
